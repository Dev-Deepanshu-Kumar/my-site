## Stack

Vanilla HTML + CSS + JS. No framework.

**Source files live in `src/` — edit those, not the output files directly.**
`css/style.css` and `js/main.js` are generated by esbuild — they get overwritten on every build.

**Build pipeline:**
```bash
npm run build   # concatenates + minifies src/ → css/style.css + js/main.js
npm run watch   # rebuilds automatically on any src/ change
```

**Deploy:**
Push to `main`. GitHub Actions runs the build and deploys to gh-pages automatically (~60s).

**Never use PowerShell `Set-Content` or `Out-File` to write source files.**
PS 5.1 adds a UTF-8 BOM that breaks special characters (—, ·, ◆ etc) and can corrupt the JS bundle.
Use VS Code, or git edits via Bash. If BOM happens: `git show <hash>:file > file` to restore.

## Common Edits

### Update a job description / quote / text
Search in `index.html` for the text. Change it.
Section comments (`<!-- ── GET /experience -->`) mark each block.
No rebuild needed — HTML is not processed by esbuild.

### Add a new skill tag
1. In `index.html`, find the right `skill-domain` block.
   Add: `<span class="skill-tag" data-ms="X">Skill Name</span>`
   Pick `data-ms` value: lower = more proficient (see legend on page).
2. In `src/js/skills.js`, find `const SKILL_DATA = {` and add:
   ```js
   "Skill Name": { synopsis: "...", usage: "...", where: "...", see: "..." },
   ```
   If you skip this, clicking the tag shows "No manual entry" — harmless.
3. `npm run build` → commit.

### Add a new company to the timeline bar
Edit `TIMELINE_PERIODS` in `src/js/timeline.js` — one array entry:
```js
{ key: 'company', start: new Date(YYYY, MM, DD), end: null, label: 'Company', color: '#hexcolor' }
```
Add the colour rule to `src/css/sections.css`:
```css
.timeline-segment--company { background: #hexcolor; }
```
Add the HTML segment in `index.html` inside `#timeline-bar`:
```html
<div class="timeline-segment timeline-segment--company" data-key="company"></div>
```
Bar widths, year labels, and legend update automatically. Then `npm run build`.

### Add a new recommendation
In `index.html`, find `<div class="rec-list">`.
Copy an existing `.rec-item` block. Swap content.
Add screenshot to `images/awards/rec-NAME.png`.
Add `<img>` inside `.rec-proof-collapse-inner`.

### Add a new award / recognition
1. Add screenshot to `images/awards/`.
2. Add entry to `data/recognitions.json`.
3. In `index.html`, find `<div class="recog-screenshots-scroll">`.
   Copy a `.recog-screenshot-item` block, update src + alt + caption.

### Add a new section (endpoint)
1. `index.html` — add `<section id="X" class="endpoint-section">` block.
2. `index.html` — add sidebar nav link in the Endpoints group.
3. `src/js/interactions.js` — add entry to `CMD_ITEMS[]` array.
4. `src/js/timeline.js` — add entry to `MOBILE_TABS[]` array (bottom nav).
   `totalEndpoints` is now derived automatically from `.endpoint-section` count — no manual bump needed.
5. `npm run build` → commit.

### Disable writing widget
In `src/js/writing.js`, change:
```js
const WRITING_WIDGET_ENABLED = true;  // ← change to false
```
Then `npm run build`.

### Update the hero photo
Replace `images/profile.png`. Same filename, no code change needed.

### Update resume PDF
Replace `Deepanshu_Kumar_Resume.pdf` at root. Same filename.

### Add a Dev.to article
Just publish on Dev.to. Widget auto-fetches latest 3. Nothing to change.

### Update api/portfolio.json
Plain JSON. Edit like a config file. Keep in sync with index.html content.

### Update llms.txt
Plain markdown. Update when: new job, new rec, new recognition.

## Gotchas

- **Edit `src/` not output files** — `css/style.css` and `js/main.js` are overwritten on every build.

- **BOM** — PowerShell `Set-Content`/`Out-File` adds BOM → corrupts bundle.
  Fix: restore from git, re-apply changes via VS Code or Bash.

- **Skill terminal** — if clicking a tag shows "No manual entry", add the key to `SKILL_DATA` in `src/js/skills.js`.

- **Command palette** — new sections need an entry in `CMD_ITEMS` in `src/js/interactions.js`.

- **Mobile bottom tabs** — new sections need an entry in `MOBILE_TABS` in `src/js/timeline.js`.

- **Local testing** — open `index.html` directly (`file://`).
  Writing widget and x-response-time won't work on file:// — test those on deployed site.

- **Encoding** — always UTF-8 without BOM. VS Code bottom bar shows encoding.

- **Revert a bad deploy** — each feature was committed separately:
  ```bash
  git log --oneline   # find the commit to revert
  git revert <hash>   # creates a new undo commit, safe history
  git push origin main
  ```
